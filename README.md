# 医学综合 · 冲刺刷题

成人高考专升本《医学综合》单文件离线刷题系统。无需安装、无需联网，浏览器直接打开 `index.html` 即用。

## 📱 在线使用

手机 / 平板 / 电脑直接打开，无需安装任何东西，进度自动存在浏览器本地：

**https://walunt.github.io/medical-exam-quiz/**

> 首次加载约 3.4 MB（题库与插图都内联在单个文件里），之后走浏览器缓存。
> 如果网络慢，也可以下载仓库里的 `index.html` 到本地双击打开，功能完全一致、且离线可用。

## 题库规模

| 题型 | 说明 | 题量 |
|---|---|---|
| A 型题 | 五选一 | 921 |
| B 型题 | 配伍选择题（5 个共用备选项对 2 道小题） | 264 |
| X 型题 | 多选，多选少选均不得分 | 132 |
| **合计** | 7 套真题（2014—2020）+ 4 套模拟卷 | **1317** |

每题均含**原卷解析**（930 题）与 **AI 解析**（1317 题），并保留原卷的「相似题 / 重复题 / 同题变体」标注。

## 功能

- **刷题**：混合随机 / 仅 A 型题 / 仅 B 型题 / 仅 X 型题 / 薄弱突击 / 错题练习 / 只刷未做题
- **间隔重复**：答对权重减半、答错翻倍，越薄弱越常出
- **错题本**：答错自动收录，答对自动移出，按错误次数排序
- **分类练习**：四种维度自由切换 —— 按章节（38 章）/ 按学科（四大部分）/ 按套卷（11 套）/ 按题型
- **模拟考试**：真实卷型 A 84 + B 24 + X 12 = 120 题 / 150 分钟；也可整套真题按原卷题号顺序作答
- **相似题对比**：43 组易混题成对呈现，含题干相似度与差异点
- **速记手册**：答案落点与多选正确项个数实测分布 + 章节题量总览
- **复习资料**：四大部分 38 章 / 309 个考点手册，章节旁可直接跳转练习
- **记忆型专项**：数值单位类 58 题、英文缩写代号类 73 题
- **题目插图**：14 道题的配图已从原卷 PDF 中裁出并内联（心电图、胸部 X 线片、体温曲线、患者面容照片），题卡内直接显示、点击可放大
- **数据管理**：进度导入导出（跨设备迁移）、弱项间隔重练、一键重置
- **主题切换**：亮 / 暗色模式

学习进度保存在浏览器 `localStorage`（键前缀 `med_`），清除浏览器数据会重置。

## 目录结构

```
.
├── index.html          # 产物：单文件刷题系统（可直接分发 / 部署 Pages）
├── template.html       # 通用引擎模板（占位符 __BANK_DATA__ 等）
├── build.py            # 构建：data/*.json + template.html -> index.html
├── figures_manifest.json   # 插图裁切清单（人工核定，属源文件，勿删）
├── data/               # 题库数据（生成物，可由脚本重建）
│   ├── bank.json       #   1317 题（含 cat 章节标签、paper 卷别、flag 数据提示）
│   ├── similar.json    #   43 组相似题对比
│   ├── memo.json       #   记忆型专项
│   ├── notes.json      #   复习资料考点手册
│   ├── meta.json       #   卷别 / 章节 / 答案分布统计
│   ├── figures.json    #   题目插图（data URI 内联，由构建脚本注入）
│   └── parse_report.json  # 解析质量报告
├── figures/            # 插图源文件（webp，构建时内联进 index.html）
├── tools/
│   ├── parse_bank.py   # 三份 md 题库 -> bank.json
│   ├── classify.py     # 按复习资料章节体系给每题打标签
│   ├── parse_extras.py # -> similar / memo / notes / meta
│   └── extract_figures.py  # 按清单从扫描 PDF 裁切插图 -> figures.json
├── source/             # 题库源文件（md，便于回溯与重建）
└── .gitignore
```

> `figures_manifest.json` 和 `template.html` 一样是**手写源文件**，不放在 `data/` 里 ——
> `data/` 是生成物目录，重建时会整个清空重跑。清 `data/*.json` 时不会误删它。

## 版本约定

- **大版本号进整数**（v1 → v2）表示里程碑，**升级前必须先与核桃确认**，不要自行 bump。
- **小版本号＝自 v1 起累计的更改次数**，每次调整 **+0.1**：`v1.0 → v1.1 → v1.2 …`
- 版本号旁固定标注 **「本系统由核桃制作」**。

版本号与署名统一由模板里的 `footerHTML()` 输出（常量 `VERSION` / `CREDIT`），
首页与设置页共用，改一处即可，避免多处不一致。

## 重新构建

```bash
python3 tools/parse_bank.py      # 题库 md  -> data/bank.json
python3 tools/classify.py        # 打章节标签
python3 tools/parse_extras.py    # 生成派生数据
python3 tools/extract_figures.py # 从扫描 PDF 裁切插图（需本机有原卷 PDF）
python3 build.py                 # 生成 index.html
```

只改了 `template.html`（界面/逻辑）时，跑 `python3 build.py` 即可。
`figures.json` 不存在时构建也能通过，只是不带插图。

**插图提取说明**：原卷 PDF 是纯扫描件（无文本层、无矢量图），所以「提取原图」实际是
「在扫描页上定位图区并按 400 DPI 重新渲染裁切」。唯一例外是 2019 年真题 44 题，
该页带一个独立内嵌图片对象，直接取了原图（页面扫描版偏暗，取内嵌图更清晰）。
裁切区域记录在 `data/figures_manifest.json`，可用 `--pdf-dir` 指定 PDF 所在目录。
若 PDF 不在本机，`figures.json` 与 `figures/` 已随仓库保存，不影响构建。

## 数据说明与已知问题

- 题目与答案以原卷为准，AI 解析为辅助学习材料。
- **插图共 13 张，覆盖 14 道题**（2018 年 51、52 题共用一张胸片）。来源与取舍：
  - 题干明确要求看图才能作答的（「心电图如下」「见下图」「图片中患者面容」「胸片如下」、
    「体温曲线」「下列心电图的诊断是」）全部补齐。
  - 题干已用文字完整描述的题**不配图**，例如「心电图示 QRS 波宽大畸形，T 波与 QRS 波相反，
    频率 150 次/分，可见房室分离」——文字信息足够解题，配图反而冗余。共 10 道此类。
  - 部分图受原扫描件质量限制（如 2014 年 66 题胸片、2019 年 44 题心电图），
    只能做到「能辨认」，达不到印刷级清晰度。做题时若看不清，建议点开放大或对照原卷。
- **章节标签为系统自动标注**，抽样准确率约 80%，个别题目可能归错；按「学科」维度（四大部分）准确率更高。以题目解析为准。
- 32 道题带数据提示（界面中会显示）：28 道部分内容为扫描件缺字后由 AI 补齐、1 道原卷附有插图但未收录、3 道选项重复（见下）。
- **3 道题的选项有重复项**（源文档 OCR 有误，系统已标记但未擅自补造内容，需对照原卷核对）：
  - 2017 年真题 A26「血液凝固各阶段都必需的因子是」：选项 `Ⅸ` 出现了两次
  - 2015 年真题 B87/B88（同组共用选项）：`胆囊` 出现了两次；该题解析里提到「胆囊**管**」，
    推测原选项之一是「胆囊管」被识别漏字
- 2020 年真题第 12 题选项行在源文档中被污染（混入 7 行其他题目的选项），已按字母首现保留，其 C 选项内容有误，建议对照原卷手工修正。
